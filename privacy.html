Privacy Policy

Effective October 11, 2026

The Mark Server is a personal-use application operated by the owner of the Google account that authorizes it. Its purpose is to download and locally organize copies of the owner's Google Drive documents for the creative writing and worldbuilding project The Mark. This application is not offered as a public service.

Information accessed

With the owner's consent, rclone uses the Google Drive read-only permission (https://www.googleapis.com/auth/drive.readonly) to access file names, identifiers, folder structure, metadata, and file contents. This Google permission technically covers files throughout the authorized Drive, although the application's intended file-copying workflow is limited to a designated project folder.

How information is used

Accessed information is used solely to create an owner-controlled local document archive, preserve revisions, and support project indexing and analysis. The application does not request Google Drive write permissions and does not intentionally modify, delete, publish, or share source files in Google Drive.

Storage and security

Downloaded files and related metadata are stored on a Linux server under the owner's control. Google OAuth credentials and refresh tokens are retained in the server's local rclone configuration to maintain authorized access. The operator is responsible for protecting that configuration and the local files with appropriate system permissions and backups. No Google Drive credentials, project manuscripts, or backup databases are placed in this public GitHub Pages repository.

Sharing, sale, and third parties

Google Drive information accessed by the application is not sold, used for advertising, or provided to data brokers. The intended workflow transfers files from Google Drive to the owner's local server, not to third-party document-processing services. Google provides the authorized Drive API, and GitHub hosts only this public informational site; the website does not display or host the Drive content.

Retention, deletion, and revocation

The owner controls how long locally downloaded files and index records are kept. They remain until removed under the owner's chosen retention or deletion procedures. The owner may revoke the application's Google account access at Google Account connections, remove OAuth tokens from the local rclone configuration, and delete local copies when no longer needed. Revoking access prevents future authorized downloads but does not automatically erase copies previously stored on the local server.

Google API Services User Data

The Mark Server's use and transfer of information received from Google APIs is limited to providing or improving this user-facing file archiving functionality. It does not use that information for advertising or other unrelated purposes.

Public website information

This GitHub Pages site is an informational website. It has no sign-in form, analytics script, or mechanism for uploading documents. GitHub may process ordinary website access data under its own privacy practices.

Contact and updates

Questions about the application or its privacy practices may be directed to the operator using the support email displayed on Google's OAuth consent screen. This policy may be updated to reflect changes in the application's actual data handling.
